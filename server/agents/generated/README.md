# Agents générés — chemin legacy

Ce dossier n'est pas une source du Registry Runtime.

La source canonique des agents enregistrés est :

`/etc/neron/data/generated_agents`

Les anciens fichiers suivis sous `agents/generated/generated` ont été archivés
avant retrait dans :

`/etc/neron/data/archive/legacy_agents/20260624T205500`

Les agents présents dans `/etc/neron/workspace/agents` restent des artefacts de
travail ou de validation. Ils ne deviennent disponibles qu'après promotion
explicite dans le Registry canonique.
